🧮 Metodología del Algoritmo

1. Sistema ELO Adaptado

Cada selección tiene un ELO histórico. La probabilidad esperada de victoria se calcula con:

P(A gana) = 1 / (1 + 10-(ELO_A - ELO_B)/400)

Bonus anfitrión: +30 ELO para USA, México y Canadá
(reducido de valores mayores para no inflar sus chances)

2. Lambda (Goles Esperados) — Modelo Calibrado

El número de goles esperados se deriva del ELO con ajustes pequeños:

λA = 2 × 1.20 × P(A gana) → rango ~0.30 a 2.80
λB = 2 × 1.20 × P(B gana) → complementario

+ Ajuste forma (±12% máx)
+ Ajuste stats (±10% máx)
+ Ajuste plantilla (±6% máx)

3. Distribución de Poisson + Corrección Dixon-Coles

P(k goles; λ) = (λk × e-λ) / k!

Corrección para marcadores bajos (ρ = -0.08):
0-0: × (1 - λA×λB×ρ) | 1-0: × (1 + λB×ρ)
0-1: × (1 + λA×ρ) | 1-1: × (1 - ρ)

4. Índice de Fuerza Compuesta (Ranking)

Rating ELO (normalizado)40%
Forma reciente20%
Stats de equipo (goles, defensa, penales)15%
Valor de plantilla10%
Historial mundialista8%
Fuerza de confederación4%
Experiencia en torneos3%

5. Simulación Monte Carlo del Torneo

Cada iteración simula el torneo completo desde fase de grupos hasta la final, generando goles aleatorios con distribución de Poisson. Se acumulan 500–10,000 iteraciones para estimar probabilidades por ronda. El error estándar con 10,000 iteraciones es <0.5%.
